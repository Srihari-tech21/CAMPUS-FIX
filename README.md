# 🏫 CampusFix - SASI Institute of Technology & Engineering (SITE)

> **"From Reporting Problems to Actually Resolving Them."**  
> *Making every campus issue visible, actionable, and accountable.*

---

## 📌 Project Overview
**CampusFix** is a digital campus issue-resolution platform custom-crafted for **SASI Institute of Technology & Engineering (SITE)**, Tadepalligudem, Andhra Pradesh.

It replaces informal verbal complaints and WhatsApp messages with a unified, transparent workflow:

$$\text{REPORT} \longrightarrow \text{PRIORITIZE} \longrightarrow \text{ASSIGN} \longrightarrow \text{RESOLVE} \longrightarrow \text{VERIFY}$$

---

## 🚀 Key Features

- **Red + White Institutional Visual Theme**: Tailored specifically to SASI Institute of Technology & Engineering's visual identity, featuring the official red SASI logo and campus photography of the 16 Pascal building.
- **Persistent Left Glass Sidebar**: Translucent glass panel with backdrop blur, smooth hover animations, and persistent menu items across every view.
- **Live Camera Capture & Photo Upload**: Students and faculty can take real-time photos of issues directly from browser/camera streams or upload file attachments.
- **Smart Priority Matrix**: Rule-based prioritization evaluating safety hazards, location density, category SLAs, and affected capacity.
- **Duplicate Issue Detection**: Automatically identifies similar reports in the same block/room to prevent ticket duplication and group student feedback.
- **Interactive Visual Timeline**: Stepper timeline (`Reported ✓` → `Reviewed ✓` → `Assigned ✓` → `In Progress ●` → `Resolved ○` → `Confirmed ○`).
- **Resolution Verification Workflow**: Prompts reporters once an issue is marked resolved (*"Is the issue actually resolved?"*) with a `✓ Confirm Resolution` option that triggers celebratory confetti 🎉.
- **Field Technician Dispatch Hub**: Dedicated maintenance view for tracking active tasks, field technician rosters, and photo thumbnails.
- **1-Click Hackathon Jury Demo Bar**: Floating assistant bar allowing judges to step through the complete flow in 7 simple clicks.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 5
- **Icons**: Lucide React Icons
- **Animations / FX**: Canvas Confetti
- **Styling**: Vanilla Modern CSS Design System (CSS Tokens & Glassmorphism)

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/Srihari-tech21/CAMPUS-FIX.git

# Navigate to project directory
cd CAMPUS-FIX

# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
